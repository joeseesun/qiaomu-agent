# 0.6.0 · 账号登录与订阅网关

- 在模型设置中登录 ChatGPT、词元跳动或 OpenRouter；保留 API Key 接入。
- 新增 Magpie 网关入口，检测本机地址并读取已登录的 Claude、Codex 等订阅模型，保留模型 ID 和思考档位。Claude Code CLI 仍可直接使用。
- 新增智谱、Z.ai、Kimi Code、MiniMax、百炼、小米与火山的 Coding / Token Plan 配置入口。

浏览器登录需要桌面版 Obsidian。国内账号登录方式、Magpie 插件差异和接入范围见[支持矩阵](../research/2026-10-11-account-and-gateway-access.md)。
