# 0.6.4 · 编辑和删除模型

- 每个模型都有编辑、删除入口，未启用的模型也能修改名称、模型 ID 和参数。
- 删除前确认具体模型；删除默认模型后切换到其余已启用模型，并清理聊天选择和最近使用记录。
- 修改 ID 时保留自定义参数，刷新列表和重启后仍保留修改；已删除的模型不会被刷新恢复，可手动重新添加。
- 保存失败保留草稿并恢复原配置，改善窄屏参数布局，补齐新增入口的中英文文案。
