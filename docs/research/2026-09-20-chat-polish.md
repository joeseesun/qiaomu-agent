# 对话交互修正

用户反馈：Mermaid 不应要求点击运行；模型切换要就地下拉；推理强度加 🧠；移除“仅建议”。

## 实现与来源

- 查阅 AI Elements Model Selector：默认 Dialog 不匹配此次明确的下拉要求，因此复用 Obsidian Menu（关闭桌面系统原生菜单，以宿主 DOM 菜单就地显示），不是再次引入 Modal。
- 模型菜单由真实后端列表生成，当前模型勾选；手动输入 ID 是单独的明确动作，仍用输入对话框。
- 输入框删除权限选择器，设置中仍保留写入权限，未改变默认值或扩大授权。推理强度按本次要求使用 🧠，其他操作保留 Lucide。
- Mermaid 11.17.2 浏览器发行版以文本嵌入，MIT 许可；完整代码块自动在 opaque-origin iframe 中渲染。sandbox 只有 allow-scripts，无 same-origin、弹窗和顶层导航权限；CSP 禁网络、外部资源、表单。宿主仓库信任不变。
- 未闭合的流式 Mermaid 只显示文本，不进入宿主 Mermaid 处理器。限制单图 20,000 字符/300 边，每条消息最多 6 个隔离图；失败或超限保留源码。
