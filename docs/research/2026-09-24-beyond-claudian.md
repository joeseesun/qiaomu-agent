# 超越 Claudian：定位与路线 · 2026-09-24

目标：能力上超过 Claudian，界面保持 ZCode 式的简洁，模型配置像 magpie 一样清楚。

## 我们已经有、Claudian 没有的

| 方面 | Claudian | 乔木 Agent |
| --- | --- | --- |
| 平台 | 仅桌面 | 桌面 + 手机（模型 API） |
| 模型来源 | 只能驱动本地 CLI，模型跟着 CLI 走 | 本地 Agent 与 27 家模型 API 在同一个选择器里，选模型即切换来源 |
| 服务商配置 | 交给各 CLI 自己管 | magpie 式列表：选厂商、贴密钥，自动拉取模型列表，密钥存在 SecretStorage |
| 中文写作与发布 | 无 | 一键发布到公众号草稿箱（博客主题、公式、Mermaid 转图） |
| 笔记动作 | 通用编辑 | 追加到今日日记或指定笔记，并可撤销 |

## 还需要补齐才能全面超越（按优先级）

1. **安全写入（已完成，2026-09-24）**：ACP 读写走 Vault API；每轮给出变更摘要和 diff；回滚前按“安全 / 用户后来改过 / 通过命令行修改”三类预检；权限请求改为对话里的审批卡片。Claudian 的审批规则做法可以复用（MIT）。
2. **选区与就地改写（选区上下文与高亮已完成；就地改写待做）**：保留编辑器选区高亮并自动作为上下文；选中文字后按快捷键原地改写，提供词级 diff 预览（参考 Claudian inline edit，MIT）。
3. **Obsidian 感知（大部分已完成）**：统一的 XML 上下文标签；移动和重命名一律走 Obsidian CLI；内置 kepano 的 obsidian-skills；库根目录的 `AGENTS.md` 作为唯一的指令来源。
4. **过程分组与运行中排队**：连续的工具调用合并成一行；运行中可以继续发消息排队，或插进去纠偏。

## 界面原则（ZCode 式简洁）

- 侧栏常驻只有标题、对话和输入框；来源、模型、推理强度都收在输入框右下角的一个按钮里。
- 设置入口只有一个（侧栏右上角），打开就是 magpie 式的“模型”页。
- 不做 Claudian 的多标签和双栏会话管理器，也不做协作模式。
